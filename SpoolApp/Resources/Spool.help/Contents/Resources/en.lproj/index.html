Spool Help

Your 3D-printing file library — watched, indexed, and organized automatically.

Spool watches folders you choose, indexes every STL, 3MF, STEP, OBJ, SVG, gcode, and OpenSCAD file it finds inside them, and keeps a searchable, thumbnailed library that stays live as files come and go — no importing, no manual re-scanning.

  • Reviewing Duplicates, Suggestions & Archives The Review window's queues, and what each one means.
  • Settings & Keyboard Shortcuts Rescan behavior, archive handling, and every shortcut Spool supports.

What Spool does for you automatically

  • Hashes and thumbnails every recognized file as soon as it appears.
  • Notices when a file moves or is renamed on disk, and keeps its tags, projects, and print history attached to the same entry rather than losing them.
  • Groups files that share a folder into a suggested project, and flags files that look like duplicates, variants, or newer versions of each other.
  • Reads embedded print settings out of Bambu 3MF projects and PrusaSlicer/other gcode footers automatically, so material, nozzle size, and print time show up with no data entry.
Spool never modifies files in a folder you granted as Library (Read-Only) — see Getting Started for what each folder type means.
