Getting Started

Grant a folder, and Spool takes it from there.

Granting your first folder

Spool only ever looks inside folders you explicitly grant it access to — this is standard macOS sandboxing, the same permission model as apps like Photos or Music. To add one:

  • Click the + button at the bottom of the sidebar, or
  • Use the File menu's "Add Drop Folder…", "Add Library Folder…", or "Add Downloads Folder…" commands — these work even if the sidebar isn't visible.

A standard Open panel appears; pick the folder you want watched. Spool walks it immediately and then keeps watching it live for as long as the app is running.

The three folder types

TypeWhat it means
Drop FolderFiles here are indexed and can be freely reorganized — moved, tagged, or deleted from within Spool. This is the one folder every library needs, and the destination new files land in when dragged into Spool or relocated from a Downloads folder.
Library (Read-Only)Files here are indexed but Spool never modifies, moves, or deletes them — safe for a folder you don't want touched, like an archive of finished prints. Duplicate files living here can never be deleted from within Spool, even during a bulk cleanup.
DownloadsNew 3D-printing files discovered here are automatically moved into your Drop Folder once indexed, keeping a real Downloads folder tidy without you having to move things by hand.

Editing, pausing, or removing a folder

Hover a folder in the sidebar's "Watched Folders" section for a pencil and a minus button:

  • The pencil lets you rename it, pause watching without losing its history (tags, projects, print log all stay attached to those files), or — for a Library folder only — switch whether new files there are indexed in place or moved into the Drop Folder.
  • The minus stops watching it entirely. This removes every indexed file, tag, project membership, and print log entry for that folder from Spool's library — the real files on disk are never touched.

Adding files directly

You can also drag files straight from Finder onto Spool's library grid. They're copied (your originals are left alone) into the active Drop Folder and indexed immediately. Dragging a file card back out of Spool onto Finder or a slicer's Dock icon works the same way a real Finder drag would.
