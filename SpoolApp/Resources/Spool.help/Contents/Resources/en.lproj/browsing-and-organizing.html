Browsing & Organizing Your Library

Grid, list, search, filter, sort

Toggle between a thumbnail grid and a compact list from the toolbar. Both share the same search field (filenames, tags, and print settings phrases like "0.2mm nozzle" or "20% infill" all match), the same sort menu, and the same filter button — a funnel icon that fills in once any filter is active. Filters cover file type, tag, star rating, printed status, material, printer profile, and slicer.

A search or filter that matches every file in a project collapses that project into a single card instead of listing each file separately — click it to see the full project.

Selecting and acting on multiple files

Click Select in the toolbar to check off files, then delete them (moved to the Trash — recoverable) or add them to a project all at once. Select All appears in the toolbar while selecting and checks off everything currently shown, including every file inside a collapsed project card; click it again (now labeled Deselect All) to clear the selection. Clicking a project card while selecting checks off every file that belongs to it as one unit, rather than opening the project — click it again to uncheck them. A fully-checked-off project card is treated as the project itself: choosing Add to Project nests it as a sub-project of the target, the same as "Move to Another Project" on its own detail page, instead of just cross-listing its files. Right-clicking any single file gives the same actions individually, plus Open With and Reveal in Finder.

The file detail page

Click any file to see its full detail page:

  • Tags — free-form labels, click the + to add one.
  • Projects — a file can belong to several. Spool auto-suggests a project for files that share a folder; suggestions show with an accent tint and a confirm/reject pair until you decide. Give a project a flag color from its detail page toolbar to make it stand out in the sidebar.
  • Related Files — duplicate/variant/derived-from/newer-version relationships, either auto-suggested from matching content or filenames, or added manually via the +.
  • Print Metadata — material, printer, slicer, and notes. Auto-filled from a Bambu 3MF project file or a PrusaSlicer-style gcode footer when Spool can read one; edit and click Save to override.
  • Printed — mark a file as printed, rate it, and leave yourself notes on how it turned out.

Renaming a file (the pencil next to its name) only changes how it's labeled inside Spool — the real file on disk keeps its actual name.

Tag, project, relationship, and rename edits are all on the system Undo stack — ⌘Z to undo, ⇧⌘Z to redo, same as anywhere else on the Mac.
